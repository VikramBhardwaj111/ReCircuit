# ReCircuit

ReCircuit is an e-waste collection website built with HTML, CSS, and JavaScript. It helps users find out which electronics are accepted, prepare their devices for drop-off, and request a pickup by email.

## Features

- Search and filter six categories of accepted electronics.
- Fill out a pickup form that opens a prefilled email draft. Review the draft and click Send in your email app.
- Use a five-step drop-off checklist that saves your progress in the browser.
- Browse a searchable list of example collection centers.
- Find contact details and prepare an inquiry email.

## How to Run

1. Clone the repository or download and extract the ZIP.
2. Open `index.html` in your browser.

## How It Works

- **HTML** contains the pages, forms, and fixed content.
- **CSS** handles the styling and responsive layout.
- **JavaScript** handles the mobile menu, search filters, checklist progress, and email drafts.
